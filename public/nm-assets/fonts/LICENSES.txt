Fonts served with the New M verification page.

Desktop view — fallbacks used only when the visitor's computer does not have the design's own fonts
(Segoe UI, Georgia, Arial). Each is metric-compatible with the font it stands in for, so text keeps the
same widths and line breaks.

Mobile view — the mobile design's own fonts, always used, so every phone (iPhones included) shows the
same letters as the design.
